## 처음 설정 (한 번만)

1. **Supabase SQL** — 대시보드 *SQL Editor* 에 `supabase/schema.sql` 전체를 붙여 넣고 Run. (제작기 `docs` 테이블은 건드리지 않는다.) schema.sql 이 바뀔 때마다 다시 Run 한다 (몇 번 돌려도 안전). 2026-10-20: `om_jset`(중간 키 자동 생성) 이 없으면 RP·지도·덱 저장이 조용히 사라진다.
2. **GitHub Pages** — 저장소 *Settings → Pages → Deploy from a branch → main / (root)*.
3. 끝. `js/config.js` 는 제작기와 같은 프로젝트를 가리키고 있다.

## 쓰는 법

- **GM**: 로비에서 「방 만들기」 → 주소창의 `#r=방id&gm=비밀값` 이 GM 링크다. 이 링크는 아무에게도 주지 않는다. 상단 「플레이어 링크」를 복사해서 나눠 준다.
- **플레이어**: 플레이어 링크로 들어와 「자리」에서 자기 트레이너 자리에 앉는다 (GM 이 파티를 불러오면 자리가 생긴다). 자리는 그 브라우저에 기억된다.
- **채팅**: `/r 1d100`, `/w 이름 메시지`(귓속말, GM 은 `GM`).
- **탭**: RP · 배틀 · 시트 · 관계도 · 캘린더. RP 와 배틀은 「무대」(GM 이 「무대로」를 누르면 모두가 그 탭으로 따라간다). 시트·관계도·캘린더는 각자 본다.
- **시트**: GM 이 「제작기에서 가져오기」로 로스터를 만든다. 캐릭터 탭의 「스탠딩」은 제작기 트레이너 시트의 스탠딩(주소)에서 따라오고, 「표정·스탠딩 편집」으로 방에서도 더할 수 있다. 전투 탭의 지령·명령은 맵툴 4식 6령 그대로 — 명령 계열(9종)을 고르면 지령 계열이 따라오고, 「일괄 제작」(횟수 + 계열 조합의 0 규칙) 뒤 항목별로 고친다. 플레이어는 자기 자리의 트레이너만 「✎ 편집」할 수 있다. 성장 탭에서 분배레벨·알까기·노력치, 전투 탭에서 지령 횟수와 「좌측/우측 진영으로」(GM). 「제작기 동기화」는 제작기 시트를 다시 읽되 개체값·소지품·HP 는 남긴다.
- **배틀 씬**: GM 이 「+ 파티」로 로스터의 트레이너를 좌·우 진영에 넣고, 에리어 수(기본 2 = 더블, 3 = 트리플)를 정한다. 벤치의 「등장」으로 에리어에 올린다.
  1. **지시 준비** — 각 플레이어(와 GM 의 NPC)가 아래 「지시 입력」에서 행동·대상·교대·우선도·지령·명령을 적고 「준비 완료」. 지시는 공개 전까지 서버의 비밀 칸에 저장된다.
  2. **턴 개시 → 지시 공개** — GM 이 「턴 개시」를 누르면 각 트레이너의 지시 입력 패널에 「에리어 A : 이름」 「지령·명령 공개」 버튼이 뜬다. 맵툴 open_command 처럼 하나씩 연다(좌석은 자기 것만, GM 은 아무 것이나). 공개된 건 카드와 로그에 보이고 지령·명령 횟수가 줄어든다. 급하면 GM 「모두 공개」.
  3. **행동 순서** — 교대 > 행동순서 변경 > 우선도(기술 우선도 포함) > 스피드(마비·순풍·습원·트릭룸 반영) > 주사위. 초상 띠로 보이고(「교대 등장」「통상 교대」「우선도」「순서값」 캡션, 트릭룸·추격 메모), GM 이 「다음 행동 ▶」로 지금 차례를 옮기면 모두에게 강조된다.
  4. **공격** — 포켓몬 카드의 「공격」: 기술·대상·보정을 넣고 「굴리기」 → 명중·급소·대미지(상성 전)·상성·최종을 보고 「적용」. 버텨라·수동 배율·반감열매·버티기는 대상마다.
  5. **랭크·상태** — 랭크 ±, 배율(mod), 상태(지속 턴), 소지품, 테라스탈. 「필드」에서 날씨·필드·룸·설치기.
  6. **턴 종료 처리** — 독·화상 등 비례 대미지, 지속 턴 감소, 임시 랭크 해제, 날씨·설치기 카운트, 턴 +1.
  - **지령·명령 자동**: 공개 때 ○○지령 → 임시 랭크 +1(전개 ×2, 방해 −1), 회복지령·치유의 법계 → HP 1/4, 영창 → 아군 전체 +1, 결계 → 벽 3T, 정화 → 상태 이상 해제. 버텨라!·맞춰라!·물러나!·피해라!·방해 지령은 대상에 표식이 붙고 공격 창이 자동 반영(방호 0.5·버티기·필중·회피). 바꿔라!·돌아와!·파계·주인의 칙령은 표식만.
  - **포텐셜 횟수**: 효과에 【N/시】가 있는 포텐셜은 카드에 남은 횟수와 「사용」 버튼.
  - **타임**: 지시 준비 중 상대 카드의 「타임」 → GM 상단에 요청이 뜨고 「허가」하면 그 플레이어에게만 결과가 보인다 (지시 랭크 A 1회·AA 이상 2회).
  - **레이드 배리어**: 「랭크·상태」에서 구간 X 를 넣으면 최대 HP 의 k/X 자리마다 하한. 닿으면 배리어 파괴·페이즈 +1.
  - **스킬 체크**: 상단 「스킬 체크」. 결과는 「로그에 올리기」로 모두에게.
  특성·소지품 효과는 아직 자동이 아니다 (설명을 보고 보정 칸에 손으로 넣는다).
- **RP 무대**: 무대 아래 입력줄에서 화자를 고르고(GM 은 나레이션·NPC·PC 전부, 플레이어는 자기 PC) 대사를 치면 그 인물의 스탠딩이 무대에 서고(화자는 테두리, 나머지는 어둡게) 검은 대사 상자에 뜬다. `*지문*` 은 따옴표 없이 기울임. 채팅 명령 `/as 이름 말`(GM) · `/s 라벨`(표정) · `/img 주소` · `/clear`(무대 비우기). 「표정」에서 인물마다 스탠딩(전신 투명 PNG)을 여러 장 넣고 골라 둔다.
- **GM 콘솔**(무대 「GM 콘솔」): 배경(그룹·최근·주소/파일 · 「배경 관리」에서 그룹/그림 추가·이름·순서·삭제, 방에 저장) · 음악(맵툴 브금 관리와 같은 꼴: 전체/그룹 탭 · 검색 · 최근 · ▶ 나만 미리듣기 · 제목 클릭 = 모두에게 재생 · 랜덤 · 곡/그룹 추가·수정·삭제는 방에 차이만 저장 · Dropbox 공유 링크는 직링크로 바꿔 줌, 플레이어는 「소리 켜기」 한 번, 음량은 각자) · 공지(프리셋 버튼 → 배너 + 로그, 편집 가능) · 지도(파티 이동·핀) · 무대·스탠딩(자리 고정, 고정 자막) · 연출(중앙 이미지·귓속말).
- **지도**: 무대 「지도」. GM 은 마커 클릭으로 공개/가리기·파티 이동, 「지도 관리」에서 모두 공개/가리기·장소 추가/이름/삭제·루트 그리기(번호 순서·색)·파티 핀 보이기/숨기기·가려진 장소 이동 시 자동 공개·인물 배치. 플레이어에겐 가린 장소가 「?」로 덮이고 숨긴 핀·루트·인물은 안 보인다. 채팅 알림 켜 두면 이동·공개가 로그에 적힌다.
- **채팅 창**: 무대와 채팅 창 사이 세로줄을 끌어 너비를 바꿀 수 있다 (브라우저에 기억).
- **덱 창**: 룰 플랜(10-19) 기본값 — 은열쇠 파티 공용 0/3, 광기 개인 0~9 (3·5·7·9 단계), 카드 5종 × 2장/부. 카드를 쓰면 은열쇠 −1, 없으면 쓴 사람 광기 +1. 「설정」에서 개인 단위로 바꾸거나 숫자·카드·NPC 를 고친다. 「새 부」로 카드 횟수 리셋.

## 권한 방식

링크 + 비밀값. 비밀값(GM·좌석)의 해시만 `om_auth` 에 저장되고, 쓰기는 전부 `om_*` 함수가 비밀값을 확인한 뒤 수행한다.
`om_auth` 와 `om_secret`(공개 전 지시 등)은 anon 이 직접 읽을 수 없어서, 개발자 도구를 열어도 남의 지시·GM 정보는 보이지 않는다.

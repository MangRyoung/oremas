오레마스 SQL

Supabase 에 서버 기능을 올릴 때 쓰는 페이지. 폰에서도 된다.

순서

  1. 아래 SQL 칸의 「복사」를 누른다.
  2. 「Supabase SQL Editor 열기」를 눌러 로그인한다 (새 쿼리 창이 열린다).
  3. 빈 칸에 붙여 넣고 Run 을 누른다. 「Success. No rows returned」가 나오면 끝.
  4. 오레마스로 돌아가 제일 먼저 가입한다 — 처음 가입한 계정이 관리자다.

「destructive operation」 경고가 뜨면 그대로 실행해도 된다 (예전 함수를 새 것으로 바꾸는 것뿐, 방 · 로그 데이터는 안 지운다). 두 번 실행해도 괜찮다.

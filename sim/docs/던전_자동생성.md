## 갈림길 · 「던전 생성」 탭 (10-28)
망령: 「던전은 생성기가 아니라 자동 생성 쪽에 기능들 넣어야 될 것 같아, 구조를 봐야 하니까. 근데 지금 이거 1갈래 길 밖에 안나오는데?」 · 「자동 생성 이름도 던전 생성으로」
- **갈림길** (`autogen.addBranches`, `o.branches` 기본 1 · 0 = 예전처럼 한 줄 · 최대 2): 본길 한 구간(방 1~2개)과 나란한 다른 길을 내고 끝에서 다시 만난다.
  - 다른 길 = 본길 구간을 뒤집어 채운다: 배틀 ↔ 체크(싸우며 뚫는 길 / 머리 쓰는 길). 방은 같은 설정으로 한 번 더 만든 던전(씨앗 +977)에서 가져온다. 방 수가 같아 길이도 같다.
  - 격자: `gridPath` 가 빈칸으로 정확히 그 걸음 수의 길을 찾는다. 못 넣으면 갈림길 없이(씨앗 1~40 × 3난이도 = 120개 중 105개에 들어감).
  - `dg.branches=[{id,from,to,main:[…],alt:[…]}]`, 다른 길 방은 `alt:'g1'`. 웹툴 JSON(toWebtool)은 방 · 통로를 그대로 싣는다.
  - 시뮬: `dungeon.pathOf` 가 판마다 갈림길에서 반반으로 한쪽을 고른다(`opt.route` = main · alt 로 고정 가능) → 승률은 두 길의 평균. 모양은 망령 10-28 00:12 확정: 「갈라졌다 다시 만나는 길」.
- **「던전 생성」 탭** (옛 「자동 생성」): 생성기 탭의 던전 하위 탭을 없애고 손잡이(지도 모양 · 갈림길 · 곁방 · 검증 루프 · 체크 목표를 일행에 맞추기 — 일행은 「돌리기」 탭에서 고른 것)를 여기로. 서버는 `genDungeon`.
  - 지도는 실제 격자 배치(`gridSVG`, 웹툴 던전 탭과 같은 자리): 본길 실선 · 다른 길 노란 점선 · 곁방 가는 점선. 좁은 화면은 격자를 눕힌다. 표는 본길 순서 → 갈림길 다른 길(구간 바로 뒤) → 곁방.
- 웹툴로 보낼 때 체크에 `auto`(던전 난이도)를 싣는다 → 웹툴이 제시할 때 그 일행으로 목표를 셈한다(skill_ui 「목표 자동」).

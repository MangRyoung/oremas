# 시뮬레이터 「생성기」 탭 (10-28)

망령: 「오리지널 특성 생성기도 시뮬레이터에 만들어서 넣게 로직 세워보자. 마음에 드는건 시뮬레이터 DB로 보낼 수 있게 하고. 야생 무리도 DB와 별개로 생각없이 눌러볼 수 있는 제작기 탭이 있는게 좋겠다. 야생/스킬/특성/던전 생성은 UI도 개선하고 생성시에 내가 어느정도 분류나 조건 설정을 할 수 있으면 좋을 것 같네」

`node bin/sim.js ui` → 「생성기」 탭. 하위 탭 다섯 개. 왼쪽 = 조건, 오른쪽 = 결과 카드. 조건은 이 브라우저에 기억된다(localStorage `sim_gen`).
카드마다 체크 → 아래 검은 띠에서 「…DB 로 보내기」. DB 목록은 결과 아래에 있고 「빼기」로 지운다.

| 하위 탭 | 조건 | 보내는 곳 |
|---|---|---|
| ✨ 특성 | 타입(최대 2) · 역할형 · TO(0.5~2 / 섞어서) · 효과 꼴 · 「시뮬이 읽는 것만」 · 개수 | `data/abil/db.json` (특성 DB) |
| 🐾 야생 포켓몬 | 등급 계단(C~A 돌아가며) · 서식지 · 타입 · 역할형 · 오리지널 특성 비율 · 실전 검토(같은 등급 1:1) | `data/wild/db.json` (야생 DB, w### 번호) |
| 🎲 즉석 무리 | 서식지 · 마리별 등급 · 가장 센 마리 보스 · 야생 Lv · 일행 · 시험 판 수 | 「야생 DB + 무리로 저장」 → `data/wild/<id>.json` (안 누르면 아무 데도 안 남음) |
| 🎯 스킬 체크 | 난이도 띠(또는 직접 %) · 테마 · 자질 고르기 · 체크 수 · 타입 조건 수 · 일행(필수) | `data/checks/db.json` (체크 DB) |

## 오리지널 특성 로직 (`lib/abilgen.js`)

1. **틀** = 제작기 특성에 실제로 있는 효과 꼴. 틀마다 기준 특성(anchor)을 두고 그 TO 를 기준값으로 쓴다.
2. 세기 손잡이(능력 칸 수 · 발동 조건 폭 · 비례 대미지)마다 TO 를 0.5 씩 더하고 뺀다.
3. 목표 TO 를 주면 정확히 맞는 것만 남긴다. 틀 하나로 모자라면 ②줄에 작은 틀(상태 면역 0.5)을 붙인다. 상태 면역은 그 타입이 원래 안 걸리는 상태는 피한다.
4. 이름 = 타입 수식어 + 틀 꼬리말. 제작기 특성 · 특성 DB 와 겹치지 않게.

| 틀 | 꼴 | TO | 기준 특성 | 시뮬 반영 |
|---|---|---|---|---|
| react | 「X」 기술을 받으면 S +1 (+2) | 1 (1.5) | 악의마음 · 주눅 (꾸덕꾸덕굳기) | 피격 반응 |
| touch | 「접촉기」를 받으면 S +1 (+2) | 1.5 (2) | 대격분 | 피격 반응 |
| cat | 「물리/특수기」를 받으면 S −1 · S +2 | 1 | 깨어진갑옷 · 벗겨진도금 | 피격 반응 |
| pinch | HP 1/3 이하 자기 타입 1.5배 (1/2 이하) | 1 (1.5) | 맹화 · 급류 · 벌레의알림 | 자동 |
| glare | 【등장】 정면 S −1 (+ 1/8 대미지) | 1.5 (2) | 재뒤집어쓰기 (위협사격) | 자동 |
| absorb | 【방호】 X 기술 무효 (+ S +1) | 1.5 (2) | 칼날잡기 · 방음 | 글만(GM) |
| cSt | 접촉기를 받으면 3할로 상태이상 | 1 | 마그마의비늘 · 저리는모피 | 피격 반응 |
| cBack | 접촉기를 받으면 공격한 쪽 1/8 | 1 | 가시비늘 | 피격 반응 |
| heal | 특정 상태일 때 턴 종료 1/8 회복 | 1 | 포이즌힐 | 시뮬 GM |
| imSt | (②줄) 상태 면역 | +0.5 | 면역 · 유연 · 불면 | 글만 |

「시뮬이 읽는 것만」을 켜면 글만 특성은 빠진다 (승률 계산에 닿는 것만).

## 특성 DB 쓰임

야생 생성(`mongen.one`)이 「오리지널 특성」 자리를 뽑을 때 특성 DB 에서 타입이 맞고 TO 가 맞는 것을 먼저 꺼내 쓴다. 맞는 게 없으면 예전처럼 즉석으로 만든다.

## API (`lib/server.js`)

`genMeta` · `genAbil` · `abilAdd` · `abilDel` · `genMons` · `monsAdd` · `genPack` · `packTest` · `packSave` · `genChecks` · `checksAdd` · `checksDel` · `genDungeon`. 일행 id 는 `id:` 를 붙여도 안 붙여도 된다.

## 1. 웹툴 그대로 쓰는 것 (lib/webtool.js 가 꺼낸 웹툴 함수)
| 일 | 웹툴 함수 |
|---|---|
| 등장 · 퇴장 · 교대 · 강제 교대 | `enterMon` · `exitMon` · `forcedSwitch` (설치기 · 배턴터치 · 오라 · 등장 효과 `autoOnEntry`) |
| 시합 개시 · 턴 개시 | `startBattle`(선발 등장 효과 스피드 순) · `setPhase(1)`(started 표시 · 턴 개시 효과 `autoTurnStart`) |
| 행동 순서 | `computeOrder`(우선도 · 효과 엔진 우선도 · 트릭룸 · 순풍 · 습원 · 날씨/필드 스피드 특성 · 구애스카프 · 따라가때리기) |
| 4식 · 6령 | `fireOrder`(이름표 · 받을 수 없는 포켓몬 막기 · 한 턴 하나 · 횟수 차감 · `applyOrder` 효과) |
| 턴 종료 | `turnEnd`(상태 · 날씨 · 필드 · 소지품 턴 종료 · 임시 랭크 · 효과 만료 · 예고 공격 · 레이드 페이즈 체인지 · 남은 턴) · 「가장 마지막 · 턴 종료 시 · 이후」 포텐셜은 자동 구문이 있으면 `fireAuto` |
| 피격 반응 | `itemHitReact` · `abilityHitReact`(특성 글 「…를 받으면」) · `itemConsume`(열매 · 띠) · `faintOff` · `faintWatch`(아군 빈사 상시 · 【자동】) |
| 효과 엔진 · 소지품 · 상태 | OM_FX(특성 · 소지품 · 포텐셜 구문) · OM_ITEMS · OM_FIELD · OM_MOVEAUTO(기술 효과 글 → 자동) |

사람이 답하던 곳(`lib/webtool.js` H.answer): 확인 창 = 예(「배턴터치인가?」만 아니요) · 효과 엔진 「조건을 만족하는가?」 = HP 조건만 읽고 나머지는 아니요 · 선택지 = 첫 줄 · 대상 = 상대면 공격/특공이 높은 쪽, 같은 편이면 HP 비율이 낮은 쪽. 물은 글은 결과의 `asked` 에 모인다.

## 2. 옮겨 쓴 것 — 공격 창 · HP 창 (lib/fight.js)
웹툴 openAttack 「굴리기 → 적용」 + 받는 쪽 openHp 「적용」과 같은 순서 · 같은 함수. 창 칸은 사람이 손대지 않았을 때 기본값(통솔 명중 · 소지품 위력 · 스킨 특성 · 날씨 · 필드 · 효과 엔진 강화/완화 · 기술 자동 급소 확정 · HP 창의 반감열매/버티기/멀티스케일/탈/피격 특성 체크).
GM 이 켜던 칸: 달인의띠(소지품이면 켠다) · 스킬링크(특성이면 켠다). 적응력은 효과 엔진이 이미 ×1.33 이라 켜지 않는다. 생명의구슬 · 도우미는 끈다.
행동 판정(혼란 · 마비 …)은 늘 켠다. 「반동 : 행동불능」 턴은 쉰다.

## 3. GM 손 처리 (웹툴에서 사람이 「발동」을 누르던 일 중 늘 하는 것 — battle3.js)
- G1 「HP : a/b 이하」일 때 상시(맹화 꼴): 그 HP 가 되면 구문을 한 번 건다.
- G2 「S」 상태일 때 턴 종료 시 HP 회복(포이즌힐 꼴): 턴 종료 전에 그 상태면 회복.
- G3 아군 빈사 상시 · 【자동】 = 웹툴 faintWatch.
- 야생 DB 오리지널 특성(112): 효과 글(abilityEff) + 자동 구문(m.auto) — 맹화 꼴 · 등장 「정면」 약화. 「…를 받으면」은 웹툴 피격 반응이 글을 읽는다.

## 4. 지시 로직 — 지침 절 → 시뮬
| 지침 | 시뮬 처리 | 코드 |
|---|---|---|
| 2-1 정보 차단 | 상대 기술은 이 배틀에서 본 것만. C = 본 것(없으면 자속기 짐작), B 이상 = 본 것 + 자속기 짐작. 자기 기술 · HP 바는 안다 | battle3 `knownMoves` · `threatVs` |
| 2-2 4식 | 지시 단계에서만(웹툴 fireOrder) · 트레이너당 한 턴 하나. 위험 기준 D = HP 35% 아래 · C = 45% · B = 본 위협 ≥ 남은 HP · A = 그리고 60% 아래. 위협이 필중기면 버텨라 | 「4식」 블록 |
| 2-3 6령 · 랭크표 | D 지령 없음. C(단순)는 지시 단계에서 바로: 위험한 아이 방어 > HP 40% 아래 회복 > 가장 센 공격수. B · A(숙달)는 ② 때만 | 「6령 · 4식 선행」 블록 |
| 2-4 숙달 ② | 순서 공개(숙달민첩: 내가 쓰러뜨릴 상대가 먼저 움직이고 +1 이면 뒤집힐 때) · 아군 명중굴림 전(이 한 방이 ×1.5 면 쓰러뜨릴 때 숙달공격/특공, A 는 빗나갈 수 있는 결정타에 숙달저격) · 상대 명중굴림 전(맞으면 쓰러지는데 ÷1.5 면 버틸 때 숙달방어/특방, A 는 못 버티면 숙달회피) · 턴 종료(지령 안 쓴 턴, HP 50% 아래 아군 숙달회복) | 각 블록 |
| 2-5 받을 수 없는 포켓몬 | 웹툴 fireOrder 의 noOrdWhy(올드 타입 · 행동불능 · 난동 · 반무적)가 막는다 + 지시가 올드 타입을 고르지 않는다 | `isOld` |
| 2-6 · 2-8 고유 · 전용 · 포켓몬 포텐셜 | 자동 구문이 있으면 등장 · 턴 개시 · 턴 종료 때 웹툴이 건다. 【N/시】 손 발동(고유 등)은 아직 안 쓴다 — 지금 시험 일행(무진 NPC 8명)에는 없다 | — |
| 2-7 습관 | 「들고 있을 법한 기술」 = 자속기 짐작(B 이상) | `knownMoves` |
| 2-9 지시 순서 | 기대 대미지 = 공격 창과 같은 보정(날씨 · 필드 · 소지품 · 특성 · 효과 엔진 · 벽 · 상성 · 자속) × 명중 확률, 주사위 중간값 | fight `estimate` |
| 2-9 ③ 지원 · 방어 후보 | 변화기 점수(「상대 HP 몇 할 깎는 공격과 맞먹나」)와 공격 후보를 견준다. 웹툴이 자동 처리하는 기술(OM_MOVEAUTO.auto) · 기술 방어만 고른다. C: 상태 이상(잠듦 0.7 · 마비 0.35~0.55 · 화상 0.5/0.15 · 맹독 0.35 · 독 0.25) · HP 50% 아래 회복 · 1턴 자기 강화 · 자기 타입을 살리는 날씨/필드. B 이상: + 기술 방어(쓰러질 위기 · 연속 X) · 벽 · 순풍 · 상대 약화 · 혼란 · 씨뿌리기 · 설치기(상대 벤치 있을 때) | fight `statusPick` |
| 2-10 교대 | D · 야생 · 보스 안 함. C = 4배 약점 + 확정 위기 때만. B 이상 = 상대 둘 모두에게 크게 맞고 벤치에 나은 아이가 있을 때. 빈자리는 턴 끝에 상성 좋은 아이(B 이상)/앞에서부터 | `wantSwitch` · `pickIn` |
| 2-11 지시력 표 | D: 눈앞(마주 선 자리) 상대 · 위력 × 상성 묶음 · 변화기 안 씀. C: HP 낮은 상대부터 · 한 마리로 충분한 상대를 둘이 안 때림 · 같은 편 맞히는 전체기 피함. B: + 쓰러뜨릴 수 있는 수 · 같은 편이 잡을 상대는 뺀다. A · AA: B + 한 상대 집중 | `choose` |
| 2-11 야생 | 야생 = 눈앞 상대에게 가장 센 공격(변화기 안 씀) · 『와일드 보스』 = C | `polOf` |
| 3-3 필중기 | 웹툴 공격 창과 같다(회피 4식이 필중기에 안 통함) | fight `attack` |

## 5. 아직 못 하는 것
- 【N/시】 손 발동 포텐셜 · 트레이너 고유 · 메가진화 · 『맞춰라!』 · 『파계』 · 전술 · 묘수(지금 시험 일행엔 없음).
- 【함성】 · 「쓰러뜨렸을 때」 같은 계기 효과 중 웹툴이 자동으로 안 하는 것(선택지 첫 줄만 고른다).
- 효과 엔진이 「조건을 만족하는가?」로 묻는 조건 중 HP 말고는 「아니요」.
- 웹툴도 손으로 처리하는 기술 효과(기술 자동화가 못 읽는 글: 플라워가드 · 지혜겨루기 …)는 효과 없음. 변화기 고르기에서 빼 둔다.
- 고정 · 변칙 피해 기술(spw.fixed)은 대미지 없음(웹툴에서도 HP 창 손 입력).
- A 의 「상대 버릇 읽기」 · AA 「끝판 계산」 · 미끼.

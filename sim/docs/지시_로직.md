# 시뮬 지시 로직 ↔ 배틀 진행 지침 대조표

> 지침 원본: 프로젝트 문서 `09_배틀_진행_지침.md`(알짜/09). 시뮬 안 사본: `docs/배틀_진행_지침.md`(2026-10-27 21시 첨부본, md5 0c5d2556c4f4…).
> 코드: `lib/battle.js` — 「지시 로직 v2」(10-27 밤). 지시는 지침 **2절**(지시 단계)을, 판정 일부는 3 · 8절을 따른다. 4절(연출) · 5절(정리) · 웹툴 조작(1-4 · 3-1 · 3-2)은 시뮬과 상관없다.
>
> **지침을 고치면 이 표를 같이 고친다.** 순서: ① `docs/배틀_진행_지침.md` 를 새 원본으로 통째로 바꾼다 → ② 바뀐 절이 아래 표에 있으면 「시뮬 처리」 칸과 `lib/battle.js` 의 해당 줄(주석에 절 번호가 붙어 있다 — `grep -n "2-4" lib/battle.js`)을 고친다 → ③ 맨 아래 「고친 기록」에 날짜 · 절 · 무엇을 적는다 → ④ 지시가 바뀌면 던전 승률이 바뀌므로 `autocheck` 를 다시 돌리고 숫자를 `docs/던전_자동생성.md` 에 고친다.

| 2-2 4식 | 선행만 · 트레이너당 한 턴 하나 · 무효도 씀 | 지시 단계에서만 정한다. 위험 기준: D = HP 35% 아래 · C = 45% 아래 · B = 본 위협 ≥ 남은 HP · A = 그리고 HP 60% 아래 | 「4식 (2-2)」 블록 |

## 시뮬이 아직 못 하는 것 (지침에는 있음)
- 특성 · 소지품 · 포텐셜(고유 · 전용 · 역할 · 메가) · 날씨 · 필드 · 설치기 · 기술 방어(방어 · 버블가드) · 연속 제한 · 난동 · 반동 행동불능 · 반무적.
- 변화기는 1턴 자기 강화만 쓴다(상태이상 · 상대 약화 변화기는 공격기가 없을 때만). 야생 DB 의 오리지널은 기술 넷 중 변화기가 2개 이상인 경우가 많아 시뮬에서 실제보다 약하게 나온다.
- 4식 『바꿔라!』 · 『돌아와!』 · 5식 · 6식, 지시 A 의 전술 · 묘수, AA 의 『맞춰라!』 · 『파계』.
- A 의 「상대 버릇 읽기」 · AA 의 「몇 턴 뒤 끝판 계산」 · 미끼.
